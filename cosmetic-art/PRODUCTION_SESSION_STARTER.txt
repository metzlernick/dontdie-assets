LEFT ARM PRODUCTION ARCHITECTURE:
- one generation pass for up to four current briefs
- 2400×2560 sheet; 4×4; 600×640 logical cells
- tiny finished cosmetic exemplar is the visual scale/style authority
- hero context screen-right; complete cosmetic screen-left
- clean white zero-contact separation
- no generated grip, hidden geometry, or AI reconstruction pass
- replacement should occupy approximately the SAME OR SMALLER total visual mass as the exemplar
- the exemplar is NOT merely a position marker
- permanent bias: WHEN UNCERTAIN, SMALLER
- slightly undersized source art is preferred because Illustrator enlargement is easy
- production priority: FINISHED-EXEMPLAR SCALE/LOCATION → SIMPLIFY DETAIL TO FIT SCALE → EXACT IDENTITY → POSE/DESIGN/VARIATION
- IF SIZE AND DETAIL CONFLICT: KEEP SMALL SIZE AND REMOVE/SIMPLIFY DETAIL
- small final size is a forcing function for extremely low detail
- long/thin/hanging objects may extend only while remaining narrow and low in total visual mass
- creatures/character-like objects receive strong miniature bias
- bottles/containers/multi-part handheld objects receive strong miniature bias
- real-world size does not control cosmetic production size
- required features repeat on every applicable row variation unless explicitly stated otherwise
- normal production briefs contain only current requested items, never calibration history or prior failures

For non-LEFT-ARM categories, use the applicable current category workflow and canonical references.
