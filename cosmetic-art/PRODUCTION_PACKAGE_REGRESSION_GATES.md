# Don't Die Cosmetic Art — Production Package Regression Gates

**Status: mandatory pre-generation and post-generation classification tests.**

These gates preserve validated category setups. They do not authorize cross-category redesign.

## Failure classification — BEFORE modifying anything

Every imperfect result is classified first as one of:

### SYSTEM FAIL
The validated category system was not obeyed or failed structurally: wrong/missing controller, wrong active-reference topology/order, wrong scale class, wrong hero/contact behavior, overlap where separation is required, wrong stage/isolation architecture, corrupted registration, or another repeatable system-level failure.

A SYSTEM FAIL may justify changing reusable infrastructure only after a concrete system cause is identified.

### BRIEF FAIL
The category system is behaving correctly but a row misses an explicit cosmetic constraint: direction/tilt, orientation, visible surface, count, color, symbol, required feature, relative position, or row identity detail.

A BRIEF FAIL never justifies reopening category architecture. Preserve the validated workflow and fix only the smallest brief-preservation/adherence issue.

If uncertain, make no architecture change until evidence establishes a SYSTEM FAIL.

## Universal packaging conditions

FAIL if fresh-agent packaging changes a category's validated input topology, substitutes or corrupts a required controller, adds reference soup, changes reference order where order matters, or rewrites a locked prompt outside permitted brief fields.

Input-controller byte/dimension checks apply where the category workflow requires an exact controller. They do not automatically make the generated model export's raw pixel dimensions an acceptance criterion.

## LEFT ARM V3 — PASSING BASELINE, CLOSED

LEFT ARM V3 is locked to:

**one-pass zero-contact generation with visible hero/context → no AI Stage B/isolation → Illustrator extraction/final placement/canonical hand overlay.**

The current passing Regression A baseline is:
1. golden ceremonial shield matching Gold Armor + Gold Sword, with broad Mirror Shield design vocabulary;
2. tan money bag with dollar sign and neck/top visibly leaning slightly left in all four variations;
3. standard silver spatula with black handle, head top-left; slots only when explicitly requested;
4. black hanging lantern with green flame.

The approved result establishes the current acceptable LEFT ARM object scale class. Shield and lantern may be modestly larger when useful while staying within the validated tiny body-relative range.

The following are **NOT LEFT ARM failures by themselves**:
- visible canonical hero/context in Stage A;
- the approved current tiny source-art scale;
- absence of an AI Stage B/isolation pass;
- generated/export raster dimensions differing from 2400×2560 when the logical 4×4 composition, body-relative placement, scale class, and zero-contact behavior remain correct;
- normal generative variation of hero pixels that does not interfere with usable cosmetic source art.

LEFT ARM SYSTEM FAIL examples:
- wrong/missing V3 controller or broken active-reference topology;
- hero/hand gripping or overlapping cosmetic source art;
- loss of clean zero-contact separation;
- presentation-sized/normal standalone props replacing the validated tiny scale class;
- introducing an AI isolation/reconstruction stage or another architecture violation.

LEFT ARM BRIEF FAIL examples:
- money-bag neck not visibly leaning left;
- requested direction/orientation omitted;
- wrong color/count/symbol/detail while the system otherwise passes.

Regression A is now the locked passing baseline. Do not continue LEFT ARM calibration unless a future run demonstrates a genuine repeatable SYSTEM FAIL.

## Cross-category rule
