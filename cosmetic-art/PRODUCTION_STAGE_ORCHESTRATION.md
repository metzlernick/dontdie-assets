# Don't Die Cosmetic Art — Production Stage Orchestration

## Universal production unit
**One cosmetic brief → four variants → one 4×1 horizontal strip.**

Historical 4×4 assets remain valid sources/evidence. New generation and generative isolation are 4×1 by default.

Every evaluation reports:
- `CURRENT STAGE: PASS | BRIEF FAIL | SYSTEM FAIL`
- `CATEGORY: IN PROGRESS | COMPLETE`

## HATS
1. 4×1 registered Stage A.
2. 4×1 foreground-only Stage B isolation; no behind-head reconstruction.
3. Deterministic registration restoration.
4. Illustrator.

## RIGHT ARM
1. 4×1 Stage A held-object generation on canonical hero.
2. 4×1 Stage B isolation + minimum hidden-grip reconstruction.
3. Deterministic scale/X/Y restoration from Stage A.
4. Illustrator.

Raw Stage-B presentation enlargement is corrected deterministically when isolation artwork otherwise passes.

## LEFT ARM
1. 4×1 zero-contact Stage A only.
2. Illustrator extraction/placement/rotation/modest enlargement/canonical hand overlay.

No AI Stage B.

The V3 tiny exemplar is a literal footprint constraint for new 4×1 production. Detail is deleted before footprint is enlarged.

If a local BRIEF FAIL repeatedly resists correction and prompt escalation starts causing scale/system regression, retain the best passing-scale result and defer tiny geometry cleanup to Illustrator rather than reopening LEFT ARM architecture.

## ARMOR / OUTFITS
1. Mandatory cape preflight. Ask if cape state is absent/ambiguous.
2. 4×1 Stage A using the validated clean-room canonical geometry/anatomy controls.
3. Optional Stage A.5 for cape correction/RESTYLE only.
4. 4×1 Stage B destructive isolation.
5. Deterministic registration restoration.
6. Illustrator.

### Armor hard rules
- 4×1 changes batching only; never weaken the validated Stage-A hand/viewer-left-arm architecture.
- faint-substrate Armor Stage A is rejected.
- if KEEP, Stage A intentionally designs/styles the cape as part of the outfit.
- Stage B preserves/removes; it never restyles.
- Stage B removes head/context/pedestal and unwanted cape while preserving approved outfit-specific hands/arms.
- no hidden garment reconstruction.
- clean Stage-B scale/X/Y drift is corrected deterministically.

The validated Animal/Fur 4×1 control demonstrated that clean-room Stage A can preserve both hands/arm chains and 4×1 Stage B can isolate successfully. Capeless isolation is also valid when requested.

## FACE ACCESSORIES
1. 4×1 Stage A on ~6% faint literal canonical substrate.
2. Deterministic faint-substrate extraction.
3. Illustrator.

No generative Stage B.

## NON-FACE ACCESSORIES
Use only an already validated location-specific workflow/controller.

## Multi-strip downstream work
Use only supplied 4×1 strips. For 1–4 strips, reduce canvas height or leave unused lower rows blank. Never invent filler. Agent performs deterministic assembly.

## Failure classification
- `SYSTEM FAIL`: validated controller/stage/scale/contact/registration architecture failed structurally.
- `BRIEF FAIL`: architecture passes but an explicit cosmetic requirement is missed.

Freeze passing controls. Do not redesign architecture for a BRIEF FAIL or generic backend error.

## Core rule
**4×1 is the scalable production unit. Validated category-specific stage controls stay frozen; downstream problems never justify regressing a passing upstream stage.**
