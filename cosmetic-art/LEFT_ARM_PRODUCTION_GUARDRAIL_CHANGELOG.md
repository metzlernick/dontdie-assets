# LEFT ARM Production Guardrail / Baseline Record

## Status

**LEFT ARM V3 is validated, passing, locked, and closed for calibration.**

## Current passing regression baseline

Approved Regression A:

- golden ceremonial shield matching Gold Armor + Gold Sword design language, using broad Mirror Shield vocabulary;
- tan money bag with dollar sign whose neck/top visibly leans slightly left in all four variations;
- standard silver metal spatula with black handle, head toward top-left; slots only if explicitly requested;
- black spooky lantern hanging downward with green flame.

This result is the current LEFT ARM production baseline.

## Architecture established by the baseline

**V3 zero-contact generation with visible hero/context → no AI Stage B/isolation → Illustrator final placement/rotation/modest enlargement if useful → canonical hand overlay.**

Expected/acceptable behavior:
- visible hero/context remains in Stage A;
- current approved object scale is valid;
- shield/lantern may vary modestly larger while remaining in the validated tiny scale class;
- no AI isolation/reconstruction stage exists for LEFT ARM;
- generated export raster dimensions are not a failure by themselves when logical 4×4 composition and body-relative relationships are correct.

## Failure classification

Before changing production infrastructure, classify the miss:

- `SYSTEM FAIL`: controller/reference/stage/scale-class/contact architecture is structurally wrong.
- `BRIEF FAIL`: the system passes but a row-specific explicit instruction is missed.

A BRIEF FAIL does not authorize a controller or architecture redesign.

## Historical guardrail retained

A prior production batch became dramatically oversized after a one-off row-specific scale exception was added to match another approved cosmetic's presentation scale. That remains prohibited: normal production must not rewrite the controller for individual objects or let semantic real-world size inflate source art toward normal standalone prop scale.

## Change-control rule

Stop calibrating LEFT ARM. Reopen only if a future run under the locked setup demonstrates a genuine, repeatable SYSTEM FAIL. Ordinary design preference or brief-adherence issues remain normal production work.
