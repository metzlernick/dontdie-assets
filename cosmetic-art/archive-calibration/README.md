## V2 / V2.1 visual-scale validation

A later production regression using golden ceremonial shield, tan money bag, diagonal metal spatula, and hanging black lantern showed that the first finished-exemplar controller could still drift toward normal readable-icon scale across unseen production briefs.

The correction deliberately changed the visual scale authority rather than adding object-specific scale prose:

- V2 used multiple tiny finished-art examples per cell. This immediately restored small production scale across all four object classes, proving the visual controller was the relevant variable. However, the generated output copied detached connector-dot artifacts from the multi-example composition.
- V2.1 replaced the cluster with **one contiguous tiny neutral finished exemplar** per cell while preserving the successful scale neighborhood. Fresh-instance regression retained small scale across shield, bag, spatula, and lantern, preserved row identity/four variations/zero-contact/detail simplification, and eliminated the detached dots.

V2.1 is now canonical. The active principle remains:

**TINY FINISHED-EXEMPLAR SCALE → SIMPLIFY DETAIL → EXACT IDENTITY → POSE/DESIGN/VARIATION.**

**WHEN UNCERTAIN, SMALLER AND SIMPLER WINS.**

Stop calibration unless a genuinely new production class exposes a repeatable failure. Do not tune the controller around ordinary one-off asset preferences; generate conservatively small and enlarge selected art later in Illustrator.
