## Current LEFT ARM conclusion

V2.1 is superseded. It passed shield/money-bag/spatula/lantern but failed to generalize to gauntlet/throwing-star/purse/nunchuks, which inflated toward hero-sized readable props.

V3 reduced the single contiguous finished exemplar to approximately 14×19 px. The difficult second regression then passed all four rows at the intended small production scale; the gauntlet also achieved palm/underside presentation.

Active principle:

**EXTREMELY TINY FINISHED-EXEMPLAR SCALE → REMOVE/SIMPLIFY DETAIL → EXACT IDENTITY → POSE/DESIGN → VARIATION.**

**SEMANTIC IDENTITY NEVER AUTHORIZES ENLARGEMENT.**

Reopen calibration only for a repeatable new V3 failure.
