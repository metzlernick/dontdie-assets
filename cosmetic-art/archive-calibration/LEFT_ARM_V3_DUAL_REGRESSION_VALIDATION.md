# LEFT ARM V3 Dual-Regression Validation

## Result

**PASS — V3 supersedes V2.1 as canonical LEFT ARM visual scale authority.**

V2.1 passed the golden shield / money bag / spatula / lantern regression but failed to generalize to a second difficult production batch: chunky gauntlet, silver throwing star, bedazzled pink purse, and red nunchuks. Those objects reverted toward hero-sized readable props; the gauntlet also showed the knuckle/back side rather than the requested palm side.

V3 changed the universal visual controller rather than adding row-specific scale exceptions. The contiguous finished exemplar was reduced to approximately 14×19 px while preserving the same hero geometry and zero-contact architecture. The production priority remained: tiny exemplar scale → remove/simplify detail → exact identity → pose → variation.

Fresh-instance V3 regression result:

- chunky golden gauntlet — PASS scale; palm/underside presentation corrected; four unoutlined red/green/blue/purple energy streaks retained
- silver throwing star — PASS scale and identity
- bedazzled pink purse — PASS scale, identity, and slight three-quarter presentation
- red nunchuks — PASS scale and identity
- four variations per row — PASS
- screen-left zero-contact — PASS
- semantic scale stability across wearable/weapon/accessory/flexible-object classes — PASS

The user explicitly accepted all four V3 rows as passing.

## Canonical lesson

The V2.1 exemplar remained too large to reliably suppress the model's semantic readable-prop prior. V3's materially smaller contiguous exemplar produced the required small production neighborhood on the regression class that broke V2.1.

Do not compensate for future object classes with bespoke scale instructions. The universal visual exemplar remains scale authority. Reopen calibration only for a repeatable failure under the V3 controller.
