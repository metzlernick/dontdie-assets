# Don't Die Cosmetic Art

Canonical production system for Don't Die cosmetic artwork.

## Start here
Fresh agents should read:
1. `FRESH_AGENT_PRODUCTION_HANDOFF.md`
2. `00_GENERATION_UPLOAD_ZIP_STANDARD.md`
3. `PRODUCTION_STAGE_ORCHESTRATION.md`
4. applicable category workflow

## Universal production unit
**One cosmetic brief → four variants → one horizontal 4×1 strip.**

Historical 4×4 calibration/production assets remain valid references and evidence, but new generation is 4×1-first.

## Category architectures

### HATS
4×1 Stage A registered on canonical hero → foreground-only Stage B isolation → deterministic registration → Illustrator.

### RIGHT ARM
4×1 held-object Stage A → Stage B isolation + minimal hidden-grip reconstruction → deterministic scale/X/Y restoration → Illustrator.

### LEFT ARM
4×1 zero-contact Stage A → Illustrator. No AI Stage B.

The V3 tiny exemplar is used as a literal footprint constraint. If detail conflicts, simplify/delete detail rather than enlarge.

### ARMOR / OUTFITS
Cape preflight → validated clean-room 4×1 Stage A → optional A.5 cape correction → destructive 4×1 Stage B → deterministic registration → Illustrator.

If cape state is missing/ambiguous, ask before Stage A. KEEP cape styling belongs to Stage A/A.5. Never weaken the validated hand/viewer-left-arm architecture to solve isolation.

### FACE ACCESSORIES
4×1 Stage A on ~6% faint literal canonical substrate → deterministic extraction → Illustrator. No generative Stage B.

### NON-FACE ACCESSORIES
Use only a validated location-specific workflow/controller.

## Packaging
Every user-facing generation ZIP is flat and directly Ctrl+A uploadable. It contains exactly the active generation files and nothing else. See `00_GENERATION_UPLOAD_ZIP_STANDARD.md`.

## Change control
Classify imperfect results as SYSTEM FAIL vs BRIEF FAIL before changing reusable infrastructure. Freeze passing controls. Do not redesign validated architecture for a local brief miss.
